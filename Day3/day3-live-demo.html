6. CSS Grid gallery — the responsive one-rule wonder

The "wow" moment of the day. Slowly resize the browser window from wide to narrow. Count: 5 columns → 4 → 3 → 2 → 1. Then ask: "how many media queries did we write?" Zero. That's the sell.

auto-fit — surviving items stretch to fill space

  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));

8. Media queries — mobile-first responsive

Resize the window to see breakpoints fire. 1 col below 600px → 2 cols at 600–1024 → 4 cols at 1024+. Open DevTools device toolbar (Ctrl/Cmd-Shift-M) and toggle between iPhone SE / iPad / desktop presets.

/* Mobile first — default rules are for phones */
.responsive-demo {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

/* Tablet — ADD complexity */
@media (min-width: 600px) {
  .responsive-demo { grid-template-columns: 1fr 1fr; }
}

/* Desktop — ADD more */
@media (min-width: 1024px) {
  .responsive-demo { grid-template-columns: 1fr 1fr 1fr 1fr; }
}

9. clamp() — fluid typography without breakpoints

Resize the window to watch this headline grow. clamp(min, ideal, max) = never smaller than min, never bigger than max, but scales smoothly between. Replaces 4–5 media queries for typography.

Three values: floor, ideal, ceiling

.headline {
  font-size: clamp(1.25rem, 5vw, 3rem);
}
/* never below 20px        */
/* tries to be 5% of vw    */
/* never above 48px        */

10. Hover transitions — the polish layer

Hover each card. 200ms is the sweet spot. Faster feels snappy, slower feels sluggish. Always animate transform — never width or top (forces relayout = jank).

Compare transition durations — hover each card

.card { transition: transform 0.2s ease; }
.card:hover { transform: translateY(-4px); }

Why transform, not width — hover both to feel the difference

/* GOOD — animates a transform (cheap, smooth) */
.good:hover { transform: scale(1.05); }

11. Common pitfall — flex items won't shrink past their content

This will trip up half the class on Exercise 3.3. A flex item containing a long URL or unbreakable text refuses to shrink. The default min-width is auto, which means "as wide as my content." Fix: min-width: 0.

The fix — uncomment min-width: 0 in DevTools

.shrink-demo .item {
  flex: 1;
  overflow: hidden;
  /* min-width: 0;  ← uncomment in DevTools */
}
